# Moonlit Survivors

An original HTML5 Canvas survival game inspired by gothic, moonlit action-survival games.

## Run Locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/`.

## Deploy

This is a static site. It can be deployed directly to Vercel from the repository root.

No build command is required. The output directory is the project root.
